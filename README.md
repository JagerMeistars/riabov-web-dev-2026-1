# Основы веб-технологий — лабораторная № 1

Главная страница компании Food Construct, доставляющей бизнес-ланчи в Москве.
Учебная работа выполнена на HTML и CSS по заданию первой лабораторной.

## Файлы

- `lab1/index.html` — главная страница.
- `lab1/menu.html` — популярные блюда.
- `lab1/delivery.html` — информация о доставке.
- `lab1/css/style.css` — общий внешний файл стилей.
- `lab1/images/lunch.jpg` — фотография из задания.
- `.htmlhintrc` — конфигурация HTMLHint из материалов курса.
- `Пояснения к защите.md` — пояснения к использованным конструкциям.

Страницы меню и доставки нужны для рабочих ссылок навигации. Функции
составления ланча и оформления заказа в первой лабораторной не реализуются.
Название компании, блюда, цены, статистика и телефон взяты из учебного макета.
Телефон является примером, а не действующим контактом сервиса.

## Просмотр

Открыть `lab1/index.html` в браузере. Для загрузки Google-шрифта нужен интернет.
Фотография и CSS находятся в проекте. Сервер и установка зависимостей
для просмотра не требуются.

## Проверка

Использовать HTMLHint с корневым `.htmlhintrc`. Конфигурация соответствует
материалам курса. CSS вынесен из HTML, для отступов использованы четыре пробела.

Проверка из терминала:

```sh
npx --yes htmlhint --config .htmlhintrc 'lab1/*.html'
```

Также проверить страницы через [W3C HTML Validator](https://validator.w3.org/nu/).

## Использованные материалы

Основная база: задание лабораторной № 1, правила оформления и сдачи,
презентации «HTML», «CSS», «Блочная модель» и «Изображения».

Дополнительные пояснения использованы только для требований задания:

- [Подключение Google Fonts](https://developers.google.com/fonts/docs/getting_started).
- [Ссылки, якоря и телефонные ссылки](https://developer.mozilla.org/en-US/docs/Web/HTML/Reference/Elements/a).
- [Структура HTML-таблицы](https://developer.mozilla.org/en-US/docs/Web/HTML/Reference/Elements/table).
- [Исходная фотография из задания](https://mospolytech-web-course.netlify.app/images/lunch.jpg).
