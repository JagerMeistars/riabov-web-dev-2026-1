## Подключение API для ЛР7–ЛР9

В СДО указано использовать приложенный `api.json` вместо старых адресов
API из методички. Этот файл описывает запросы эмулятора, но не содержит
адрес сервера. Адрес и исходники эмулятора не были предоставлены.
Поэтому подключение к серверу преподавателя пока не настроено.

В `lab7/js/api.js`, `lab8/js/api.js` и `lab9/js/api.js` нужно указать
адрес эмулятора в `API_URL`. Пустая строка означает тот же сервер,
на котором открыта страница. Пути запросов: `/labs/api/dishes`
и `/labs/api/orders`.

Для ЛР8–ЛР9 в `API_KEY` указывается ключ учебного сервера.
Он передаётся только в строке запроса. Согласно приложенному описанию,
эмулятор без параметра `--key` принимает любой непустой ключ и разделяет
по нему заказы пользователей. Ключ, выдаваемый другим сервером,
следует брать у преподавателя.

Клиентские сценарии проверены с тестовыми ответами API.
На реальный сервер заказы при проверке не отправлялись.
На GitHub Pages собственного API нет, поэтому без отдельного адреса
меню и заказы ЛР7–ЛР9 не загрузятся.

В ЛР3–ЛР7 форма по заданию отправляется на `https://httpbin.org/post`.
Для проверки используйте вымышленные контактные данные.
Форма обратной связи в ЛР10 проверяет поля в браузере и ничего не отправляет.
