# Пояснения к лабораторной № 1

**Структура.** `header` содержит название и навигацию. Основное содержимое
находится в `main`, тематические части — в трёх `section`. `h1` задаёт
главный заголовок, `h2` — заголовки разделов. В `footer` находятся контакты.

**Списки и таблица.** `ul` — маркированный список, каждый пункт находится
в `li`. В таблице `thead` объединяет заголовки, `tbody` — строки данных.
`tr` задаёт строку, `th` — заголовочную ячейку, `td` — ячейку данных.
`scope="col"` связывает заголовок с соответствующим столбцом.

**Ссылки.** `href="menu.html"` открывает соседний файл. Ссылка
`href="#contacts"` переходит к элементу с `id="contacts"` на этой странице.
Здесь этот идентификатор присвоен футеру. `tel:` перед номером позволяет
открыть приложение для звонков. Учебный номер из макета вымышленный.

**CSS.** Файл `css/style.css` подключён через `link`. Селектор `h2` выбирает
все заголовки второго уровня, `.container` — элементы с этим классом,
`footer a` — ссылки внутри футера, `header.container` — шапку с классом
`container`. Идентификатор футера используется для якоря, а оформление
задаётся тегами и классами.

**Блочная модель.** `margin` задаёт внешний отступ, `padding` — внутренний.
`box-sizing: border-box` применён через `*` ко всем элементам: объявленная
ширина включает внутренние отступы и границы. `max-width` ограничивает
ширину содержимого, а `margin: 0 auto` размещает ограниченный по ширине
блок по центру. Последовательность блоков определяет обычный поток документа.

**Изображение.** `src` указывает локальный файл, `alt` описывает фотографию.
HTML-атрибуты `width` и `height` передают исходные размеры. CSS ограничивает
ширину изображения доступным местом, а `height: auto` сохраняет пропорции.

**Шрифт и цвет.** Google Fonts подключён отдельным `link`, а `font-family`
на `body` задаёт Roboto для текста страницы. Текстовые свойства наследуются.
Для ссылок семейство и размер также указаны явно по требованию задания.
Arial и `sans-serif` служат запасными вариантами при недоступности Roboto.

**Таблица и состояния ссылок.** `border-collapse: collapse` объединяет
соседние границы ячеек. `padding` создаёт отступы внутри ячеек, `text-align`
выравнивает их содержимое. `:hover` меняет цвет ссылки под указателем мыши.
У ссылок в чёрном футере собственные светлые цвета, чтобы текст был читаемым.

**Что разобрано дополнительно.** Полные примеры якорей, телефонной ссылки,
разметки таблицы и подключения Google Fonts изучены для прямых требований
задания. Ссылки на дополнительные источники приведены в README.
